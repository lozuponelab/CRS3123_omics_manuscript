# Manuscript Figures

Provides the `R` script, `.rdat` objects, and associated `pdf`/`png` outputs for the manuscript figures.  

## General pointers

- `.rdat` objects for individual plots (found under `ggplots`) were read into `figures.Rmd` where `cowplot` was then used to assemble the figures
- figures were output as `pdfs` (better quality) and `pngs` (to be compatible with powerpoints and word documents)
