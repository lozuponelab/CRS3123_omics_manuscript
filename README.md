# CRS3123_omics_manuscript
This repository includes all code needed to reproduce analysis and figures for CRS3123 -omics manuscript (Apgar and Lyon et al., currently in submission)

## Directory contents are as follows: 
Each directory contains a ```README.md``` file that includes additional information about the code/data provided
- analysis: This folder is split into folders containing the four main types of analysis within the manuscript (16S rRNA, shotgun metagenomics, metabolomics, and fecal immune profiling)
- figures: Compiled manuscript figures and the script used to produce them, plots taken from all directories
- data_submission: Files used to submit raw data to public repositories
