# CRS3123 -omics manuscript

This repository includes all code needed to reproduce analysis and figures for CRS3123 -omics manuscript (Apgar and Lyon et al., currently in submission)

## Directory contents are as follows:

Each directory contains a `README.md` file that includes additional information about the code/data provided

- [analysis](https://github.com/lozuponelab/CRS3123_omics_manuscript/tree/main/analysis): This folder is split into folders containing the four main types of analysis within the manuscript ([16S rRNA](https://github.com/lozuponelab/CRS3123_omics_manuscript/tree/main/analysis/1_16S_rRNA), [shotgun metagenomics](https://github.com/lozuponelab/CRS3123_omics_manuscript/tree/main/analysis/2_shotgun_metagenomics), [metabolomics](https://github.com/lozuponelab/CRS3123_omics_manuscript/tree/main/analysis/3_metabolomics), and [fecal immune profiling](https://github.com/lozuponelab/CRS3123_omics_manuscript/tree/main/analysis/4_fecal_immune))
- [manuscript_figures](https://github.com/lozuponelab/CRS3123_omics_manuscript/tree/main/manuscript_figures): Compiled manuscript figures and the script used to produce them, plots taken from all directories
- [data_submission](https://github.com/lozuponelab/CRS3123_omics_manuscript/tree/main/data_submission): Files used to submit raw data to public repositories
